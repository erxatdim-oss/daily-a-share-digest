# A股短线王

双击 `打开A股短线王.command` 即可启动本地工作台。

也可以在终端运行：

```bash
zsh start_daily_digest.sh
```

首次运行会自动准备本地 Python 环境并安装 `streamlit`、`pandas` 等依赖，之后会直接打开浏览器。

默认端口：`http://localhost:8503`

功能：

- 自动拉取主要指数、自选股和持仓行情
- 显示市场温度、交易阶段、今日主线、风扇叶片、蜂巢资金迁徙
- 显示持仓浮盈亏、成本距离、日内位置和关键风险线
- 提供 MACD、KDJ、RSI、BOLL、MA5/10/20/60、量能比和技术评分
- 提供外部市场雷达、主力净流入/流出、热点板块和热股排行
- 提供低吸观察、顺势观察、仓位管理、做T辅助、主力动向、回测工具和交易复盘
- 提供可复制的文本版研究合集

注意：

- 本软件仅作研究观察，不构成个性化投资建议。
- 行情源可能延迟或不可用，交易前以券商和交易所数据为准。
- 如果 macOS 提示“无法打开，因为无法验证开发者”，右键脚本，选择“打开”。
