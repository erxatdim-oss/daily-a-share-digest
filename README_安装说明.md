# A股每日动态合集

双击 `A股每日动态合集.app` 即可打开。

如果你把文件夹分享给别人，也可以让对方双击 `start_daily_digest.sh` 或 `打开A股每日动态合集.command`。首次运行会自动准备本地 Python 环境并安装 `streamlit`、`pandas`，之后会直接打开浏览器。

功能：

- 自动拉取主要指数
- 自动拉取自选股和持仓行情
- 显示市场温度、交易阶段、今日主线、风扇叶片、蜂巢资金迁徙
- 显示持仓浮盈亏、成本距离、日内位置和关键风险线
- 提供交易员信号队列、观察窗口、资金适配观察池
- 提供 MACD、KDJ、RSI、BOLL、MA5/10/20/60、量能比和技术评分
- 提供可复制的文本版每日动态合集

默认端口：`http://localhost:8503`

注意：

- 本软件仅作研究观察，不构成个性化投资建议。
- 行情源可能延迟或不可用，交易前以券商和交易所数据为准。
- 如果 macOS 提示“无法打开，因为无法验证开发者”，右键脚本或 app，选择“打开”。
